# تغيير كلمة مرور مدير الطلاب أو المبيعات

الأمر جاهز على إصدار API الحالي. لا تحتاج تعديل الكود أو ملف البيئة. الأمر يغيّر كلمة مرور حساب المدير النظامي الموجود فقط، ويحافظ على إيميله ومعرفه وصلاحياته وبياناته، ثم ينهي جلساته على الويب وAndroid. لا يُنشئ مديراً جديداً ولا يمس حسابات الطلاب أو المدير الآخر.

من PowerShell افتح اتصالاً تفاعلياً:

```powershell
ssh -t -i "C:\Users\ROG\Downloads\studentry-server.pem" ubuntu@51.21.248.126
```

على السيرفر، لمدير الطلاب:

```bash
cd /var/www/studentry/current
sudo -u www-data php artisan studentry:manager-password student_manager
```

ولمدير المبيعات:

```bash
sudo -u www-data php artisan studentry:manager-password sales_manager
```

اكتب كلمة المرور الجديدة مرتين عندما يطلبها؛ لن تظهر الأحرف. يلزم 12–100 حرفاً مع حروف وأرقام. لا تمرّرها كوسيط --password ولا داخل أمر SSH أو .env. بعد النجاح يدخل المدير على الموقع والتطبيق بالكلمة الجديدة. الحسابات الأخرى لا تُسجّل خروجاً.

ملف /var/www/studentry/shared/manager-credentials.txt يعرض بيانات الإنشاء الأولى فقط، ولا يغير قاعدة البيانات. بعد تغيير كلمة مرور مدير يصبح ما في الملف قديماً لذلك الحساب؛ الأمر لا يكتب كلمة المرور الجديدة كنص صريح في الملف. خزّنها في مدير كلمات مرور خاص بك. لم يتم تغيير كلمات المرور تلقائياً أثناء التجهيز.

فُحص اختيار الحساب ومنع الحساب المفقود أو المكرر، تأكيد كلمة المرور، بقاء الهوية، وإلغاء جلسات المدير المحدد فقط. أمر --no-interaction رُفض فعلياً على الإنتاج دون تغيير الحساب.
