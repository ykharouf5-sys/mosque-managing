# سياسة خصوصية Studentry — مسودة تحتاج مراجعة قانونية

تاريخ النفاذ: `[يُحدد قبل النشر]`

الجهة المسؤولة عن البيانات: `[الاسم القانوني والعنوان ووسيلة التواصل]`.

يجمع Studentry بيانات الحساب والتواصل والملف الأكاديمي، والبيانات التي يدخلها المستخدم لإدارة المرضى والمواعيد والمدفوعات، ومعرّفات الأجهزة اللازمة للإشعارات. تُستخدم البيانات لتقديم الخدمة، حماية الحساب، المزامنة، إرسال الإشعارات المطلوبة، دعم المستخدم، ومنع إساءة الاستخدام.

قد نعالج البيانات عبر مزودي الاستضافة وقواعد البيانات والبريد والإشعارات والتخزين، وفق عقود تحمي السرية. لا نبيع البيانات الشخصية. يجب إدراج أسماء المزودين ومواقع المعالجة ومدد الاحتفاظ الفعلية قبل اعتماد هذه السياسة.

نحتفظ بالبيانات فقط للمدة اللازمة لتقديم الخدمة والوفاء بالالتزامات القانونية. يستطيع المستخدم طلب الوصول أو التصحيح أو التصدير أو حذف الحساب والبيانات عبر `[البريد/الرابط]`، مع بيان الاستثناءات القانونية ومدة تنفيذ الطلب.

نستخدم تشفير النقل، صلاحيات وصول، سجلات تدقيق ونسخاً احتياطية. لا توجد وسيلة تقنية تضمن أمناً مطلقاً، وسنطبق إجراءات الاستجابة والإخطار المطلوبة عند وقوع حادث.

لا يجوز استخدام التطبيق لإدخال بيانات مرضى حقيقية قبل تحديد الأساس القانوني، اتفاقيات المعالجة، سياسة الاحتفاظ، وآلية الاستجابة لطلبات أصحاب البيانات وفق الدول المستهدفة.

للتواصل بشأن الخصوصية: `[privacy@example.com]`.

> هذه مسودة تشغيلية وليست استشارة قانونية. يجب اعتمادها من مستشار قانوني وفق أسواق النشر.
