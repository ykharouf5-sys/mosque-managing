# شروط استخدام Studentry — مسودة تحتاج مراجعة قانونية

تاريخ النفاذ: `[يُحدد قبل النشر]`

تحدد هذه الشروط العلاقة بين المستخدم و`[الاسم القانوني]`. يجب قبل النشر استكمال: أهلية المستخدمين، وصف الخدمة، قواعد الحسابات، الاستخدام المقبول، مسؤولية المحتوى والبيانات الطبية/الأكاديمية، الدفع والاسترجاع، الملكية الفكرية، الإيقاف والحذف، حدود المسؤولية، القانون والمحكمة المختصة، ووسيلة التواصل.

لا يقدم التطبيق تشخيصاً أو نصيحة طبية، ولا يغني عن الأنظمة والسجلات المهنية المطلوبة قانوناً. المستخدم المخول مسؤول عن صحة البيانات وعن الحصول على الموافقات اللازمة لإدخال بيانات أشخاص آخرين.

> هذه مسودة وليست استشارة قانونية، ولا يجوز نشرها قبل المراجعة القانونية.
